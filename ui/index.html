    Interceptor

    The local-first triager. It answers deterministic requests from the local model and calls PASS to hand everything else to normal routing.

    Providers

    Each provider is an OpenAI-compatible endpoint with its own credentials and connection pool. Saving rebuilds only the changed provider; its model cache reloads in the background.

    Routing policy — system prompt

    The interceptor sends this system prompt to the local model with every eligible request. It decides which requests the local model answers itself and which it PASSes to external routing. Saving writes it back to the config file.
